# AWS HA Task Manager DevOps

A simple full-stack Task Manager application designed to be deployed on AWS using a High Availability architecture.

## Stack
- React.js
- Node.js / Express
- PostgreSQL
- Docker
- AWS EC2
- AWS RDS
- AWS Application Load Balancer
- CI/CD with GitHub Actions
- Monitoring with Prometheus and Grafana

## Goal
Deploy the application on two EC2 instances with a shared PostgreSQL RDS database and automatic failover using AWS Load Balancer.
